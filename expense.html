Expense Tracker

Project Overview

What I built

Transaction Management

Add, edit and remove income and expense transactions with useful descriptions, categories and dates.

Financial Summary

Automatically calculate total income, total expenses and the current balance from stored transactions.

Responsive UI

Designed the interface to work across desktop and mobile screens with a clean and simple user experience.

Project Architecture

Three-tier deployment

Frontend Layer

Separate frontend tier for the user-facing expense application.

Backend Layer

Dedicated backend service with documented API endpoints for application operations.

Database Layer

MySQL database tier for persistent application data.

Infrastructure & Traffic

Terraform-managed infrastructure with a load-balancer configuration (lb.conf) connecting traffic to the application tiers.
